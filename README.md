# Empresa de Agentes IA - 100% Gratis no GitHub

Baseado na sua ideia: empresa so de agentes virtuais (Marketing, Vendas, TI)
Rodando o funil: Publico/Nicho -> Anuncios R$90/dia -> Pag Venda -> Checkout Hotmart -> WhatsApp

## Como rodar (100% gratis)

1. Crie conta no groq.com (gratis) e pegue a API KEY
2. No GitHub: Settings > Secrets and variables > Actions > New repository secret
   Name: GROQ_API_KEY
   Value: sua chave gsk_...
3. Va em Actions > Roda Empresa IA > Run workflow

O resultado fica em Actions > ultimo run > Artifacts > resultado-empresa
